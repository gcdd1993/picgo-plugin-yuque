# picgo-plugin-yuque

PicGo 语雀图床插件，通过语雀 Web 端上传接口将图片上传到语雀图床。

## 功能特点

- 支持上传图片到语雀图床（`cdn.nlark.com`），公开文档的图片可公网直链访问
- 只需配置语雀 Cookie 和一个文档链接，文档 ID 会自动从链接解析
- 支持多种图片格式（JPG、PNG、GIF、WebP）

## 安装

### 通过 PicGo 安装

1. 打开 PicGo
2. 点击「插件设置」 -> 「搜索插件」
3. 搜索 `picgo-plugin-yuque`
4. 点击安装

### 手动安装

1. 下载项目文件到本地任意位置
2. 在 PicGo 的「插件设置」页面，点击「导入本地插件」
3. 选择本插件文件夹后导入即可

## 配置

### 获取语雀 Cookie

1. 访问 [语雀](https://www.yuque.com/) 并登录
2. 按 F12 打开开发者工具，切换到「网络」（Network）选项卡
3. 刷新页面，找到任意一个发往 `www.yuque.com` 的请求
4. 在「请求标头」中复制完整的 `Cookie` 请求头值（确保其中包含 `yuque_ctoken` 和 `_yuque_session`）
5. 粘贴到插件的「语雀 Cookie」配置项中

### 获取文档链接

1. 在语雀中打开任意一篇你有编辑权限的文档
2. 复制浏览器地址栏的链接，形如 `https://www.yuque.com/用户名/知识库/文档slug`
3. 粘贴到插件的「文档链接」配置项中

> 上传的图片会挂载到这篇文档下（作为附件）。图片本身是独立 URL，不会改动文档内容；如需清理可在该文档的附件管理里删除。

### 在 PicGo 中配置

1. 打开 PicGo
2. 点击「图床设置」 -> 「语雀图床」
3. 分别填入「语雀 Cookie」和「文档链接」
4. 点击「确定」保存配置

## 使用

配置完成后，选择「语雀图床」作为默认图床，上传图片即可。上传成功后 PicGo 会自动生成 `cdn.nlark.com` 的图片直链。

## 注意事项

- Cookie 会过期，上传失败（如提示 401/需要登录）时请重新抓取 Cookie
- 请妥善保管 Cookie，它等同于你的登录凭证，不要泄露给他人
- 私有知识库的图片直链可能带签名时效，外链能否长期访问取决于文档的公开状态
- 本插件仅供个人学习交流使用，请勿滥用
